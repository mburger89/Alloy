# Alloy 0.1.0

First public release of Alloy, a native macOS code editor built around AI coding sessions.

## Requirements

- A Mac with Apple silicon, running macOS 14 or later.
- At least one coding agent installed and signed in. Claude Code is supported directly. Codex, Gemini CLI, OpenCode, Goose or an agent you add run over the Agent Client Protocol. Alloy does not install agents.

## Sessions and chat

- Run several sessions at once on one project folder, each with streaming chat, collapsible thinking, tool blocks, permission cards, question cards and plan cards.
- Choose the agent for each session from the New Session menu: Claude Code, Codex, Gemini CLI, OpenCode, Goose or a custom agent. API keys for agents are kept in the macOS Keychain only.
- API keys can be entered in Settings > Agents and are stored in the Keychain.
- Composer with @file and slash-command completion, image paste and drop, queued messages, and mode and model controls.
- Sessions can be renamed and forked. Sessions and history persist per project and resume on your next message.
- One window per project; open several windows to work on several repositories.

## Who changed what

- Every line is attributed to the session that wrote it, to you, or to an outside change, with gutter bars and tints.
- Keep or revert each edit. Side-by-side diff with synchronised scrolling.
- Changes made by a session's shell commands are attributed to that session.

## Working together

- Sessions share what they have read through small notes, so a second session does not re-read the same files. Notes are tied to the file's state and are not served once the file changes. You can turn sharing between projects off in Settings.
- Warnings when a session is about to edit lines another session, or you, is changing. Warnings never block an edit.
- Sessions can message each other and claim a region of a file. Alloy flags two parties repeatedly rewriting the same lines.

## Code mode

- Switch between Chat and Code. Code mode has a file tree, tabs, split panes, and a narrow chat column.
- Syntax highlighting (tree-sitter) for Swift, Python, JavaScript, TypeScript, TSX, JSON, Markdown, Bash, Rust, Go, C, C++, YAML, HTML and CSS.
- Multiple cursors, code folding, find, quick open, command palette, and rebindable keyboard shortcuts.
- Project-wide search and replace with regular expressions and include and exclude globs; results respect .gitignore.
- Git: change bars in the gutter, blame, compare with the last commit, stage, commit and switch branches.
- Built-in terminal running your login shell, with links, find and a confirmation before multi-line pastes.
- CSV and TSV files open as a table: check what a session changed cell by cell, fix values in place, and switch to Text any time.

## Language servers

- Alloy uses language servers you already have installed (rust-analyzer, sourcekit-lsp, typescript-language-server, pyright, gopls, clangd and others; you can add your own).
- Diagnostics and linter warnings, completion with snippets, signature help, hover, go to definition and references, rename, quick fixes and formatting.
- Alloy never installs or updates servers.

## Appearance

- Six built-in themes: Dracula (default), Alloy Dark, Alloy Light, Solarized Dark, Solarized Light, One Dark. Themes can follow the system appearance.
- Your own themes are JSON files that apply live. In a Claude Code session, type /theme to have it draft one.
- Rounded "island" layout with an optional glass effect, both adjustable in Settings.

## Updates and privacy

- Alloy checks for updates once a day through Sparkle and installs when you quit or choose Restart to update. You can turn automatic checks off in Settings.
- No telemetry and no account. Alloy does not write to ~/.claude or your project's .claude folder.
- Alloy's local tool server listens on 127.0.0.1 only.

## Known limitations

- Intel Macs are not supported.
- Plugins are not part of this release.
- Early software: expect rough edges.
