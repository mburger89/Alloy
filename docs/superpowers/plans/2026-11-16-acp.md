# ACP (Agent Client Protocol) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a session run any ACP v1 agent (Codex, Gemini CLI, OpenCode, Goose, custom) next to the unchanged native Claude session, with the same chat, coordination and attribution features.

**Architecture:** A new UI-free module `AlloyACP` (JSON-RPC over newline-delimited stdio, tolerant v1 Codable models, connection) plus `ACPTransport: SessionTransport` that translates ACP into the existing `InboundMessage`/`OutboundMessage`, so Transcript, ledger and coordination code is reused and the Claude path stays byte-for-byte unchanged. `Session`/`SessionRecord` gain a `backend`; `Workspace` picks the transport by backend through an injected second factory (AlloyCore cannot import AlloyACP, so `main.swift` injects it). UI work (menus, pickers, settings) lands last, each with its frame-guard test.

**Tech Stack:** Swift 6.1, SwiftPM, MetalUI (read-only), Swift Testing, Security.framework (Keychain). No new package dependency.

**Spec:** `docs/superpowers/specs/2026-11-19-alloy-acp-design.md` (research notes: `docs/acp-research.md`). Executors read both; the spec's "Approved decisions" and the orchestrator rulings are binding.

## Global Constraints

- Claude sessions untouched at every step: the existing suite (WorkspaceTests, ClaudeProcessTests, InboundDecoderTests, TranscriptTests, ForkTests, ...) passes unchanged. Existing `Workspace.init(makeTransport:)` call sites in tests keep compiling.
- Frame guards never rise: `ViewRerunTests.steadyFrameRequests` 88, chat 46, `CodeModePerformanceTests.steadyCode1/2/3` 91/107/117 (code 46/62/72 request guards), `knownPopoverGap` 0, steadyCompare 77, terminal guards (`knownVisibleTerminalGap` 0, `knownTerminalViewExcess` 0, `visiblePanelBaseline` 55), idle 0. A hidden or closed feature and an idle ACP session cost 0 per frame.
- Tests run only as: `lockf -k <the swift test lock> swift test --no-parallel [--filter X]` from the worktree; plain `swift build` needs no lock. Known flaky alone-passing: OverlapIndexTests.unsavedTypingCostIsBounded, ByteCopiesTests.readHoldsOneCopy, LSPManagerLinterTests.probeAnswersAreCachedUntilReload, ViewSelectionTests.aJumpScrollsOnlyThatPanesView.
- Missing MetalUI API: stop and report a MetalUI gap; no workaround or substitute.
- Secrets only in the Keychain (service `dev.alloy.agent-secret`, account `<agent id>/<VARIABLE_NAME>`, accessible when unlocked, this device only); never in files, settings.json, history, logs or error text. Unit tests inject a fake secret store and never touch the login Keychain; one opt-in integration test uses a throwaway keychain file.
- `protocolVersion: 1`; decode tolerantly (ignore unknown fields and update variants). Advertise only implemented client capabilities: `fs.readTextFile`, `fs.writeTextFile`, `auth.terminal`, `session.notices`, `session.compaction`; never `terminal`.
- Alloy never installs software; never `npx -y`; Codex preset command is `codex-acp`; install hint `npm install -g @agentclientprotocol/codex-acp`.
- Agent writes only inside the project root (symlinks resolved); protected paths (`.git/`, `.env`, `.env.*`, `opencode.json`, `.claude/`, `.codex/`, `.goose/`, `.gemini/`, `.vscode/`, git hooks, MCP config files) always need the user's approval.
- Never launch GUI apps, never spawn subagents, no broad pkill (kill only PIDs you started, agent processes included), no bare `git stash`, no Docker, never write `~/.claude` or the project's `.claude`.
- Committed files contain no local paths, user names, session URLs, bundle ids of the developer or personal email (the privacy pattern given in the branch brief; commit trailers excepted). Recorded fixtures are scrubbed of paths, usernames, tokens, account details.
- Every commit message ends with the two attribution trailer lines given in the branch brief (Co-Authored-By Claude Opus 5.5, then Claude-Session), verbatim.

## Review Focus

- A multi-megabyte single JSON line, a stray non-JSON stdout line, or an agent that closes stdout mid-turn: no hang, no crash, an exit notice (Task 2 and 4 tests).
- Agent write via `fs/write_text_file` to `../outside`, a symlink escaping the root, or `.env`: refused or approval-gated, never written silently (Task 5).
- A permission request arriving after Stop, or a late `tool_call_update` after `cancelled`: answered `cancelled` / still applied, no stuck `awaitingPermission` (Task 4).
- Restored ACP session with a missing or truncated history file, or an agent lacking resume/load: dormant shows what exists, wake falls back to `session/new` with the notice (Task 6).
- A secret-looking env variable in the plain list, Keychain denied or unavailable: refused with the exact message, agent launches without it, chat names the missing variable, nothing written to disk (Task 3, 6).
