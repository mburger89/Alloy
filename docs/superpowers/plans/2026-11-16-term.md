# Terminal panel (Alloy side, no MetalUI terminal API) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything of the integrated terminal that Alloy can build and test without a pty or emulator: lifecycle hooks, layout model and persistence, settings, theme tokens, link detection, and the bottom panel shell with a placeholder pane view.

**Architecture:** Pure value types in AlloyCore (`TerminalSplitTree`, `TerminalLayout`, `TerminalSettings`, `TerminalPalette`, `LinkDetector`), held by `Workspace` and persisted through `UIState`. The panel (`TerminalPanelStore`, `TerminalPanel`, tab strip, placeholder pane) lives in AlloyKit and enters `CodeIslandRow` only while visible, so a hidden panel adds nothing to the element tree.

**Tech Stack:** Swift 6.1, SwiftPM, MetalUI (read-only), Swift Testing, `MetalUITesting` `TestWindow`.

**Spec:** `docs/superpowers/specs/2026-11-16-terminal-design.md` (design tasks 2, 3, 4 and 6; "Approved decisions" at its end are binding).

## Global Constraints

- Work only on branch `feat/term`. Tests run only as `swift test --no-parallel [--filter X]` wrapped in the swift test lock (`lockf -k <lockfile> swift test ...`; the orchestrator supplies the lockfile). Plain `swift build` needs no lock.
- Known flaky, ignore if they fail alone under load: `OverlapIndexTests.unsavedTypingCostIsBounded`, `ByteCopiesTests.readHoldsOneCopy`, `LSPManagerLinterTests.probeAnswersAreCachedUntilReload`.
- Frame guards must not rise: `ViewRerunTests.steadyFrameRequests` 88, `CodeModePerformanceTests.steadyCode1/2/3` 91/107/117. Idle frames cost 0 element requests. A hidden or closed feature costs nothing per frame.
- MetalUI is read-only. If an API is missing, stop and report a MetalUI gap; no workaround or substitute.
- Out of scope: any pty, emulator, `PtySpawner`, `AlloyTerminal` target, `TerminalView`, key capture, command retargeting of ⌘W/⌘T/⌃Tab/⌘\\ (design tasks 5, 7, 8). Chat mode hides the panel. Zero warnings.
- Accessibility id on every control; theme tokens only (no hard-coded colours in views).
- Committed files contain no local paths or personal data (no user names, home-directory paths, scratch-directory paths, session URLs, bundle-id prefixes or personal emails; the orchestrator supplies the exact grep), except commit-message trailers. No bare `git stash`.
- Every commit message ends with the exact two trailer lines the orchestrator supplies (Co-Authored-By, then Claude-Session).
- Defaults pinned by the spec: panel default height 30 % of the island, minimum 4 rows; split autosave name `code-terminal` (via `splitStore`, so the height lands in `Workspace.paneSizes`); `UIState.currentVersion` stays 1; scrollback default 10 000; option-as-meta default on; cursor default block with blink on; multi-line paste confirm default on; toggle ⌃\` (View menu "Toggle Terminal", id `view-toggle-terminal`); new tab ⌃⇧\`.

## Review Focus

1. A `ui-state.json` whose `terminal` value is malformed, has duplicate pane ids, a dangling `activeTab`/`focusedPane`, or zero tabs must load to a valid layout (or nil), never corrupt the file or crash. Pinned in Task 3.
2. Closing the last terminal tab: the panel hides and the layout is empty; toggling again creates one tab (no empty visible panel). Pinned in Task 2.
3. A stop hook added while `stopAll()` runs, or a slow hook, must not skip or serialise the others; each hook runs exactly once even if `stopAll()` is called twice. Pinned in Task 1.
4. Quit with several busy terminals asks once (plural text), a second quit request while the alert is open does not stack a second alert, and Cancel replies `false` without saving or stopping. Pinned in Task 9.
5. Link text edge cases: trailing punctuation (`foo.swift:12:3:`, `(foo.swift:12)`), `http://host:8080` is a URL not `host:8080` a path, Windows drive `C:\x.swift:3`, `../` escapes outside the project, paths with no line. Pinned in Task 6.
