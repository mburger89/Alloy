# Terminal input half (keys, paste, selection, find, links) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the terminal panel usable: keys, IME text, paste and focus reports reach the shell; selection, copy, select-all, clear, find and clickable links work, with the registry commands retargeting while a terminal is focused.

**Architecture:** `TerminalView` already encodes keys, IME text, paste, focus reports and mouse, selects, copies on the copy shortcut and offers links; Alloy only supplies `onInput` (bytes to the pane's pty), `onLink`, `keyCaptureExceptions`, `optionAsMeta`, `cursorStyle`. Everything the view does not do (select-all, clear scrollback, find, multi-line paste confirm, opening links) goes through the pane's `TerminalSnapshotSource.perform` and public emulator API, behind a small `TerminalScreen` helper in AlloyTerminal, and is reached by registry commands that read `Workspace.terminalFocusActions` inside their closures (as `tab.*` does).

**Tech Stack:** Swift 6.1, SwiftPM, MetalUI `MetalUITerminal` / `MetalUITerminalUI` (read-only, master f7901d3e), Swift Testing, `MetalUITesting` `TestWindow`.

**Spec:** `docs/superpowers/specs/2026-11-16-terminal-design.md` (design task 7, input half; goals 8 and 9, "Calls settled up front" 2 and 3, and "Approved decisions" are binding). Output half: `docs/superpowers/plans/2026-11-16-term3.md`.

## Spikes and gaps (decide at the task named, report, never substitute)

1. **Paste interception (Task 4).** `TerminalView` pastes by itself (`pasteDestination`, Edit > Paste, its own shortcut) with no host hook. The plan routes the paste shortcut through an Alloy command by listing it in `keyCaptureExceptions`. Spike first: with the exception listed, does the shortcut reach the Alloy command and does the view's own paste stay silent? If Edit > Paste (menu click) still bypasses the confirm, or the view still pastes on the shortcut, report "MetalUI gap: no paste hook on TerminalView" and ship the command path only if the bypass is closed; otherwise stop at the spike and report.
2. **Select-all and clear scrollback (Task 2).** Neither has a named emulator API. `emulator.selection` is settable and `firstRow` is public: select-all is `selection = .linear(TerminalRange(firstRow...last))` set inside `source.perform`. Clear scrollback is the emulator's own ED 3 (`CSI 3 J`) fed through `source.feed`, only if the emulator implements it (spike with a byte-stream test); else report the gap.
3. **Revealing a find match (Task 5).** `search(_:from:backwards:)` and `scrollViewport(toOffset:)` are public. Revealing needs the live-bottom row to turn an absolute match row into an offset. If no public emulator or snapshot value gives it, report "MetalUI gap: reveal a row / scroll to row" and do not ship find reveal.
4. **Selection redraw (Task 2).** After a programmatic `selection` set inside `perform`, the view must redraw (a snapshot carries `selection`). If it does not, report the gap.

## Review Focus

- A terminal command (copy, paste, find, select-all, clear) fired with no terminal focused or a pane exited or without a session: no-op, no crash, no pty write (Tasks 2, 3).
- Pasting an empty string, text with ESC / `ESC[201~`, a 1 MB blob, CRLF and lone-CR line endings, and exactly one line with a trailing newline (counts as 1 line, no confirm) (Task 4).
- A path link on a row with wide characters or a path that escapes the project (`../..`), a symlink out of the project, a missing file, and a line number of 0 or 10^12 (Task 6).
- Find with an empty needle, a needle matching nothing, wrap-around at both ends, and the bar open while the shell exits or the pane is closed (Task 5).
- Typing while scrolled back snaps to the bottom (MetalUI does it): a regression test that input keeps working after find moved the viewport (Tasks 1, 5).
