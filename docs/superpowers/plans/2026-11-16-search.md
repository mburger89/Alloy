# Project Search and Replace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Project-wide search and replace in Code mode: a streaming, cancellable engine over `FileIndex`, a Search sidebar tab, and replace written as ledger edits reviewed with Keep All / Revert All.

**Architecture:** A UI-free `SearchEngine` actor in AlloyCore scans `FileIndex` paths (open documents from snapshots) and streams batches to `SearchModel` (`@MainActor @Observable`, `@ObservationIgnored` on `Workspace`). `SearchView` in AlloyKit is the only reader of observed search state. Replace goes through the workspace and ledger: open documents via one `CodeBuffer.transaction` plus `save`, closed files via the save slot and `writeKeepingMode`, every edit tagged with one `group: UUID?` on `EditRecord`.

**Tech Stack:** Swift, SwiftPM, MetalUI (read-only, no workarounds), Swift Testing, `memmem`/`fnmatch` from Foundation (Linux-safe).

**Spec:** `docs/superpowers/specs/2026-11-16-project-search-design.md` (read its "Approved decisions" section: 1(a), 2(a), 3(c)).

## Global Constraints

- Work only in the `feat/search` worktree. MetalUI is read-only; a missing MetalUI API is reported as a MetalUI gap, never worked around. Conditional gap: `List` append rebuilding existing rows (Task 4 guard).
- Tests run only through the swift test lock with `swift test --no-parallel [--filter X]`; plain `swift build` needs no lock. Known flaky under load: `OverlapIndexTests.unsavedTypingCostIsBounded`, `ByteCopiesTests.readHoldsOneCopy`, `LSPManagerLinterTests.probeAnswersAreCachedUntilReload`.
- Frame guards must not rise: `ViewRerunTests.steadyFrameRequests` 88, `CodeModePerformanceTests.steadyCode1/2/3` 91 / 107 / 117; idle frames cost 0 element requests; a hidden or closed feature costs nothing per frame.
- Ledger field is `public var group: UUID?` on `EditRecord`, decoded with `decodeIfPresent`, no migration. `Author` is unchanged (`.user`). Code intelligence reuses this exact field.
- Replace All above 1,000 matches confirms first; at or below applies immediately.
- Menu items are added in one small isolated block of `AppCommands.swift` (a command registry lands on another branch; they get ported on rebase).
- Settings and ui-state decode leniently: `(try? c.decodeIfPresent(...)) ?? default`; `UIState.currentVersion` stays 1.
- Cross-platform: one Swift engine, no `rg`/`grep`/platform search APIs, shortcuts use `.command`. AlloyCore search files compile on Linux (no AppKit, no `Darwin`-only calls outside what `FileIndex` already uses; use `#if canImport(Darwin)` otherwise).
- Limits (spec calls 6 to 9): skip files over 16 MB (`Workspace.previewLimit`) and files with NUL in the first 8 KB; regex lines over 64 KB skipped, 250 ms regex budget per file; 4 workers in index order; files over 4 MB read one at a time; previews capped at 200 characters; caps 10,000 matches / 2,000 files; batches flush every 50 ms or 500 matches; reorder buffer 256 files.
- No local paths or personal data in committed files (the orchestrator's privacy pattern list applies). Commit messages end with the two trailer lines the orchestrator specified (Co-Authored-By Claude Opus 5.5, then Claude-Session).
- Zero compiler warnings. No subagents, no GUI launches, no broad `pkill`, no bare `git stash`.

## Review Focus

Inputs the spec implies but no existing test covers; each has a pinning test in the named task.

1. Multibyte text (emoji, combining marks, CJK) before a match: byte ranges must select and replace the right characters. Task 1 (`SearchQueryTests`), Task 5 (`ReplacePlanTests`).
2. CRLF files: `$` matches before `\r`, replace keeps `\r`, preview has no `\r`. Task 1, Task 5.
3. File saved or moved on disk between search and Replace All: skipped and listed, nothing written. Task 5, Task 6.
4. Searching while a file is open and dirty, then replacing: earlier typing saved as its own `.user` edit, replace is its own tagged edit, one Cmd+Z restores. Task 6.
5. Empty or invalid query/regex, zero-width regex matches, project closed mid-search: no hang, no result, clear message. Task 1, Task 2, Task 4.
