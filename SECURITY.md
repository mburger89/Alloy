# Security policy

## Reporting a vulnerability

Report vulnerabilities privately. Open the repository's Security tab and choose "Report a vulnerability". This uses
GitHub private vulnerability reporting.

Do not use public issues for vulnerabilities.

Please include:

- The Alloy version.
- Your macOS version.
- The steps to reproduce the problem, and what you expected to happen.

Response is best effort. This is a small project, and replies can take a few days.

## Supported versions

Only the latest release gets security fixes.
