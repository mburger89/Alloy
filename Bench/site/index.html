Features

Many Claude sessions. One folder.

Run several Claude Code sessions side by side, each with rich chat: plans, questions and permission requests you answer in place.

Know who changed what.

Every line is coloured by the session that wrote it. Per-session diffs; keep or revert an edit in one click.

Sessions that don't collide.

Alloy warns a session before it edits lines another session (or you) is changing, so work doesn't get overwritten.

A real code editor, too.

Code mode puts a full editor beside your sessions: language servers, split panes, Git and a built-in terminal, all drawn on the GPU.

Code mode

Everything you need when you take the wheel.

When you want to write the code yourself, Alloy is a complete editor.

Code modeFile tree, tabs and split panes. Switch between chat and code in one click.
Language serversCompletion with snippets, hover, go to definition and references, rename, quick fixes and formatting, with errors and linter warnings as you type.
EditingMultiple cursors, folding, find, and search and replace across the project. Command palette, Quick Open and your own shortcuts.
GitChange bars in the gutter, blame with author and age, compare with the last commit, stage, commit and switch branches.
TerminalA built-in terminal with clickable links, find, and a check before multi-line pastes.

Privacy

Your code stays yours.

  • No telemetry and no account. Alloy runs the Claude Code you already have.
  • It never changes your Claude Code settings — the optional theme skill is installed only when you click it.
  • The update check is the only network call Alloy itself makes.
FAQ

Questions

Is it free?

Yes. Alloy is open source under the MIT licence.

Do I need a Claude subscription?

Yes — Alloy runs your own Claude Code, so you need Claude Code installed and logged in (a Claude subscription or API account).

Does it run on Intel Macs?

Not yet: Apple silicon only.

How do updates work?

Alloy checks for updates once a day in the background. It installs when you quit or when you choose Restart to update — never mid-session.

How is it so fast?

It's native Swift drawn straight to the GPU with Metal, and it only does work for what's on screen.
